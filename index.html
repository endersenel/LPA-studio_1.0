Methodological Framework & Equations

Formal documentation matching Mplus and tidyLPA standards for manuscript integration.

1. Finite Mixture Model Specification

Latent Profile Analysis assumes the population is a mixture of $K$ distinct normal distributions. The marginal density of observation $y_i$ is defined as:

f(y_i; \Psi) = \sum_{c=1}^K \pi_c \phi(y_i; \mu_c, \Sigma_c)

where $\pi_c$ represents class mixing proportions ($\sum \pi_c = 1$), and $\phi$ is the multivariate normal density.

2. Information Criteria & Classification Entropy

  • AIC: $-2\ln(L) + 2q$
  • BIC: $-2\ln(L) + q\ln(N)$
  • SABIC (Sample-Size Adjusted BIC): $-2\ln(L) + q\ln(\frac{N+2}{24})$
  • Entropy: Normalized Shannon entropy based on posterior probabilities $p_{ik}$, evaluating classification certainty between 0 and 1. When class collapse occurs ($N_k = 0$), entropy is undefined or set to 0.0 to prevent false perfection.

3. Bootstrap Likelihood Ratio Test (BLRT)

Compares model $K$ against $K-1$ classes by generating bootstrap samples under the null hypothesis, providing rigorous empirical $p$-values.
