Data Import

Import a rectangular dataset, inspect the variables, and select numeric indicators for Gaussian latent profile analysis.

Data requirements: The first row must contain variable names. Each subsequent row should represent one participant. LPA indicators must be numeric. Rows with missing or non-numeric values on selected indicators are excluded from model estimation, while the original row indices are preserved for later assignment.
