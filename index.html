3. Model Specifications

Methodological Notes

The model assumes conditionally normally distributed continuous indicators. This implementation uses diagonal covariance matrices. Therefore, residual covariances between indicators are not freely estimated within profiles.

Model selection should not rely on one statistic alone. Consider BIC, SABIC, AIC, entropy, likelihood-ratio tests, profile sizes, substantive interpretability, and solution stability.

Profiles with fewer than five observations or less than five percent of the analyzed sample are flagged as potentially unstable.

The BLRT is computationally intensive because each bootstrap replication refits both the K-profile and K-1-profile models.
