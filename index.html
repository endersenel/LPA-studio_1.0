Methodology & Statistical Framework Report

This section details the formal statistical models, equations, and estimation algorithms utilized within the SPPLab studio, structured for thesis and journal manuscript integration.

1. Latent Profile Analysis (LPA) & Mixture Modeling

Latent Profile Analysis (LPA) is a model-based person-centered clustering technique designed to identify unobserved heterogeneous subpopulations (latent profiles) within continuous multivariate data. The marginal density of an observation $y_i$ is defined as a finite mixture of multivariate normal distributions:

$$f(y_i; \Psi) = \sum_{c=1}^{K} \pi_c \, \phi(y_i; \mu_c, \Sigma_c)$$

Where $K$ represents the number of latent profiles, $\pi_c$ is the mixing proportion (class probability subject to $\sum \pi_c = 1$), $\mu_c$ is the class-specific mean vector, and $\Sigma_c$ denotes the variance-covariance matrix. Parameters are estimated using the Expectation-Maximization (EM) algorithm with multi-start initializations. Full covariance matrices are strictly projected onto the cone of symmetric positive-definite (SPD) matrices using Jacobi eigenvalue decomposition with eigenvalue clipping ($\epsilon = 10^{-6}$).

2. Model Selection & Enumeration Criteria

To determine the optimal number of latent profiles ($K$), multiple information criteria and likelihood-based statistical tests are evaluated:

  • Akaike Information Criterion (AIC) & Bayesian Information Criterion (BIC): Lower values indicate superior model parsimony and fit. BIC incorporates sample size penalization.
  • Sample-Size Adjusted BIC (SABIC): Utilizes Sclove's (1987) scaling factor $\ln((n+2)/24)$, mitigating sample-size bias in finite mixture modeling.
  • Entropy: Measures classification certainty ranging from 0 to 1, where values $\ge 0.80$ denote high classification accuracy.
  • Bootstrap Likelihood Ratio Test (BLRT): Evaluates model improvement between $K-1$ and $K$ profiles via parametric bootstrapping ($B=100$) with resilient replicate tracking.

3. Profile Validation: Exact ANOVA & Chi-Square Tests

Following profile assignment via posterior probabilities, external validation is conducted:

  • Exact ANOVA & Eta-Squared ($\eta^2$): Continuous distal outcomes are evaluated across profiles using exact $F$-distribution survival functions, with effect sizes quantified via partial eta-squared ($\eta^2 = SS_{between} / SS_{total}$).
  • Pearson Chi-Square & Cramer's V: Associations between categorical covariates and latent profile membership are tested using the incomplete gamma function CDF, measuring nominal association strength via Cramer's V.

4. Joint Softmax Multinomial Logistic Regression & Pseudo-Inverse SE

To examine the simultaneous impact of multivariate predictors on latent profile membership, a true joint multinomial logit model is estimated using Newton-Raphson maximum likelihood optimization. Profile 1 serves as the reference category:

$$P(C_i = c \mid X_i) = \frac{\exp(\beta_{c0} + \beta_c' X_i)}{1 + \sum_{j=2}^{K} \exp(\beta_{j0} + \beta_j' X_i)}$$

Standard errors for original-scale intercepts and slopes are derived from eigenvalue-based pseudo-inverse of the Fisher Information matrix. Condition numbers exceeding $10^{12}$ trigger automatic ill-conditioning flags to prevent singular matrix artifacts.
