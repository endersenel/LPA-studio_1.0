Latent Profile Analysis (Gaussian Mixture, EM Algorithm)

Methodology: For each K (number of latent profiles), a Gaussian mixture model with class-specific means and class-specific diagonal variances is estimated via the Expectation-Maximization (EM) algorithm. Multiple random starts are used to reduce the risk of local optima; the solution with the highest log-likelihood is retained. Model fit is summarized by log-likelihood, number of free parameters (q), AIC, BIC, SABIC, and entropy. Two likelihood-ratio tests for the number of profiles are provided:

LMR-LRT (approximate): A boundary-corrected likelihood-ratio test comparing the K-class model to the (K-1)-class model. Because mixture models have parameters on the boundary under the null (a class proportion can be zero), the p-value is approximated by a 50/50 mixture of χ² distributions with df and df-1, where df = 2p + 1 (p = number of indicators). This is a widely used approximation; for publication, confirm with specialized software (e.g., Mplus) if the result is borderline.

BLRT (bootstrap): A parametric bootstrap likelihood-ratio test. Data are simulated from the fitted (K-1)-class model; both the (K-1)- and K-class models are re-fit to each simulated sample. The p-value is the proportion of bootstrap LRT statistics that exceed the observed LRT. BLRT is generally more reliable than LMR-LRT but is computationally intensive.

Small-class warning: Any profile with n < 5 or < 5% of the sample is flagged as potentially spurious/singular and should not be interpreted as a meaningful latent class. Model selection should consider fit indices, classification quality, theoretical meaning, and parsimony together—not BIC alone.

Exhaustive Profile Group Comparisons (ANOVA & Chi-Square)

Methodology: Compare a selected external variable across the latent profiles identified in the LPA step. For continuous variables, a one-way ANOVA is computed from the profile-specific means, sum-of-squares, F statistic, and p-value. For categorical variables, a Pearson chi-square test of independence is computed from the observed cross-tabulation, with Cramer's V as an effect-size measure. These tests are run using the modal profile assignment from the currently selected K-class model. Because assignments are based on posterior probabilities, the tests treat profiles as known groups; this is standard but slightly underestimates uncertainty compared to mixture-model-based approaches (e.g., the BCH procedure in Mplus).

Multinomial Logistic Regression (Predicting Profile Membership)

Methodology: Predict modal profile membership from selected numeric covariates using multinomial logistic regression. Profile 1 is the reference category. Coefficients are estimated by gradient ascent with a diagonal IRLS (Newton-type) approximation, which is stable for browser-based computation. Predictors are internally standardized to z-scores so that coefficients and odds ratios are comparable across variables. Standard errors are approximate and assume a diagonal observed information matrix; when predictors are highly correlated, these standard errors may be slightly underestimated. For final publication, confirm with a dedicated statistical package (e.g., R, Stata, Mplus) if coefficients are borderline significant.

Longitudinal Latent Profile Transition Analysis (LPTA)

Methodology: Select the Time 1 and Time 2 categorical variables (e.g., previously assigned latent profile labels at two measurement occasions). A real cross-tabulation is computed from the paired observations, showing counts and row percentages of transitions. The stability rate is the percentage of cases that remain in the same category from Time 1 to Time 2. Both variables must be recorded for the same cases; rows with missing values on either variable are excluded.
